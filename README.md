# <img src="IMG_8701.png" width="28" height="28" alt=""> Snack Chooser

오늘 먹고 싶은 간식을 고르기 어렵다면 Snack Chooser가 도와드려요! 과자, 아이스크림, 전통 간식, 사탕·젤리와 음료를 둘러보고 랜덤 추천도 받아보세요.

👉 **바로 사용하기:** <https://ctm1102.github.io/snack_chooser>

## 이렇게 이용해 보세요

- **카테고리 선택:** 과자, 아이스크림, 전통 간식, 사탕·젤리, 음료를 골라 살펴보세요.
- **랜덤 추천:** 오늘 먹을 간식을 재미있게 뽑아보세요.
- **즐겨찾기:** 로그인한 뒤 마음에 드는 간식의 별표를 눌러 저장하고, 즐겨찾기만 모아볼 수 있어요.
- **알러지 설정:** 회원가입 때 알러지를 선택하면 해당 성분이 포함된 간식을 목록에서 제외해요. 제품별 실제 성분은 포장지 정보를 꼭 확인해 주세요.

## 회원가입과 로그인

이메일 주소 대신 이름과 비밀번호로 가입하고 로그인할 수 있습니다. 회원가입 시 알러지 정보도 선택할 수 있어요. 로그인하지 않아도 간식 목록과 랜덤 추천을 이용할 수 있습니다.

## 프로젝트 안내

Snack Chooser는 별도의 설치 없이 웹 브라우저에서 이용할 수 있는 반응형 웹 앱입니다. 모바일과 데스크톱 화면을 지원합니다.

서비스를 실행하려면 현재 저장소의 Supabase 설정이 유효해야 합니다. 운영자 또는 개발자는 Supabase 프로젝트 설정에서 공개용 Publishable/anon API 키를 확인해 앱 설정과 일치시키세요. 비밀번호는 Supabase Auth가 관리하며 앱에서 직접 저장하지 않습니다.

## 만든 이유

간식 고르는 작은 고민을 쉽고 즐겁게 해결하고, 알러지 설정을 통해 선택에 참고가 되는 정보를 제공하기 위해 만들었습니다.
