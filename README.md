# 🍪 Snack Chooser

간식을 랜덤으로 추천해주는 웹 서비스입니다.

## 🚀 기능

- 간식 랜덤 추천
- 카테고리별 간식 목록
- Supabase 기반 로그인 및 회원가입
- 아이디와 비밀번호 인증
- Supabase Auth의 안전한 비밀번호 해싱 및 세션 관리
- 회원가입 시 알레르기 선택 및 닫기 버튼 제공
- 로그인한 사용자의 알레르기에 맞는 간식 필터링
- 즐겨찾기 저장
- 간식 상세 알레르기 정보 확인
- 쿠키 이모지 로고

## 🔐 계정 및 Supabase

로그인과 회원가입은 Supabase Auth를 사용합니다. 비밀번호는 앱에서 평문으로 저장하지 않으며, Supabase가 자동으로 안전하게 해시하고 인증 세션을 관리합니다.

사용자가 입력한 아이디는 내부적으로 `아이디@snack.local` 형태의 이메일로 변환되어 Auth 계정 식별자로 사용됩니다.

알레르기, 즐겨찾기 등 사용자 정보는 `profiles` 테이블에 저장됩니다.
